WHAT THIS PATCH CHANGES
- First registration is category-first.
- Active Admin-created categories appear automatically.
- Level choices are restricted to the selected category.
- Existing authenticated Students can self-enroll in an active category.
- An Admin-disabled/inactive enrollment cannot be self-reactivated by the Student.
- Existing enrollment level changes still use the level-change workflow.
- Server validates category, level, enrollment, slot/category match, eligibility, capacity and weekly quota.
- Legacy General English API behavior is retained for backward compatibility.
- Admin's basic Student edit no longer overwrites official category-level enrollment.
